# Studio On Screen App

Downloads for the **Studio On Screen App**: an on-air screen for the RØDECaster Duo and Pro, for Mac and Windows.

**Download the latest version:** see [Releases](../../releases/latest).

This repository only hosts the installers. More at [studioonscreen.com](https://www.studioonscreen.com).

## Free beta

This is an early version. It is not yet signed with an Apple or Microsoft certificate, so your computer will warn you the first time you open it.

**Mac:** open the `.dmg`, drag *Studio On Screen* to Applications, then right-click it and choose **Open** (click Open again when asked). If macOS still refuses, go to *System Settings → Privacy & Security* and click **Open Anyway**.
Not sure which Mac you have? Apple menu → *About This Mac*. "Apple M1/M2/M3/M4" means Apple Silicon; "Intel" means Intel.

**Windows:** run the installer. If Windows SmartScreen appears, click **More info → Run anyway**.
